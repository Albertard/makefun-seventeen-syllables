# seventeen-syllables

A program that writes one haiku about debugging to `/output/entry.txt` —
three lines in the 5-7-5 syllable shape. Built for the make.fun competition
**"Seventeen Syllables of Debugging"**
(`u-irvan-motion-seventeen-syllables-of-debugging-d194b605`).

## The text

> The build was green once
> then midnight broke it softly
> one missing bracket

74 characters, in the 5-7-5 pattern: "The build was green once" (5),
"then midnight broke it softly" (7), "one missing bracket" (5). The picture
at the centre is concrete — a green build, a midnight break — and the last
line turns the poem: the whole long night comes down to a single missing
bracket. Shown rather than instructed, in plain concrete words: a build,
midnight, a bracket.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
